# 班咭正式版本架構

## 已確認設定

- 正式入口：`https://staff.jiggerflip.com`
- 工作地點：4C 工作室，大角嘴合桃街 2 號福星工廠大廈 4C 室
- 工作地點座標（由 Google Maps 連結解析）：`22.3225694, 114.1629615`
- Plus Code 參考：`85F7+25 大角咀`
- 定位半徑：50 米
- 超出範圍：標記為需要主管核實（可按公司政策改為禁止打卡）
- 超出 50 米仍可打卡，但紀錄標記為「需要主管核實」，並通知主管
- 角色：管理員、主管、一般員工
- 登入：手機號碼＋一次性驗證碼；裝置登入狀態持續，不需每日重新登入
- 班次：支援跨日班次，例如 `16:00–01:30`
- 補卡：員工提出、主管審批
- 提醒：開工前、下班前、遲到即時通知主管
- 保存：打卡及定位紀錄 7 年

## 敏感資料設計

身份證號碼及銀行戶口屬高度敏感資料，與一般員工資料分開保存：

1. 使用伺服器端加密保存，不能在前端或瀏覽器保存完整值。
2. 一般畫面只顯示遮罩值，例如 `******1234`。
3. 只有獲授權的管理員可以查看，主管及一般員工不能查看銀行資料。
4. 查看、修改、匯出均寫入不可刪除的審計紀錄。
5. 員工列表、班表及一般報表不包含銀行戶口資料。
6. 匯出敏感資料需要再次驗證及明確權限，並記錄操作者。

## 建議服務分層

- 網頁及手機 PWA：`staff.jiggerflip.com`，全站 HTTPS。
- 身份驗證：手機 OTP、持續登入工作階段、裝置撤銷。
- 應用程式資料庫：員工、角色、班表、預設班次、假期、補卡申請。
- 敏感資料庫：加密身份證及銀行資料、金鑰不與資料庫放在一起。
- 打卡服務：伺服器時間、定位座標、定位精度、工作地點距離、裝置及驗證結果。
- 通知服務：開工前、下班前及遲到通知。
- 審計服務：登入、查看、修改、匯出及審批紀錄。

## 正式上線前必須完成

- 在 DNS 將 `staff.jiggerflip.com` 指向正式部署平台。
- 取得 4C 工作室的實際地圖座標，不能只依賴文字地址。
- 設定加密金鑰、資料庫備份、存取權限及 7 年保存政策。
- 以香港《個人資料（私隱）條例》要求準備收集目的、保留期限及員工告知內容。
- 進行手機定位、跨日班次、補卡審批、權限及災難復原測試。

> 原型階段的 `localStorage` 只可用於測試，不可保存正式員工身份證或銀行戶口資料。
